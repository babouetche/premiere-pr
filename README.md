# premiere-pr

Dépôt d'entraînement pour apprendre à utiliser Git et GitHub.

## Objectif

Ce dépôt sert à pratiquer le cycle de contribution complet :

1. créer une branche ;
2. modifier un fichier ;
3. faire un commit ;
4. pousser la branche sur GitHub ;
5. ouvrir une Pull Request (PR) et la fusionner.

## Commandes utiles

```bash
git switch -c ma-branche      # créer une branche et s'y placer
git add README.md             # préparer un fichier pour le commit
git commit -m "Mon message"   # enregistrer la modification
git push -u origin ma-branche # envoyer la branche sur GitHub
gh pr create                  # ouvrir une Pull Request
```
