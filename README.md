# Retro Succès

Appli web (installable sur téléphone) pour suivre ses succès [RetroAchievements](https://retroachievements.org).

- **Mon profil** : points, jeux maîtrisés, succès récents
- **Mes jeux** : progression par jeu, filtres et tri
- **Chercher un jeu** : par console + nom, liste complète des succès (débloqués / à faire)
- **Chercher un joueur** : profil, succès récents et jeux d'un autre joueur

Au premier lancement, renseigner son pseudo et sa Web API Key (retroachievements.org → Settings → Keys).
La clé est stockée uniquement dans le navigateur de l'appareil.

La modification du profil n'est pas possible via l'API (lecture seule) : un bouton renvoie vers la page Settings du site.
